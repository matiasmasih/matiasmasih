## Reporting a Vulnerability

I take security seriously and appreciate your help in keeping this project safe.

### How to Report

If you discover a security vulnerability, please:

1. **Email me directly**: [matiasmashl@gmail.com](mailto:matiasmashl@gmail.com)
2. **Include details**: Please provide a clear description of the vulnerability, including:
   - The project/file affected
   - Steps to reproduce the issue
   - Potential impact
   - Any suggested fixes (if applicable)

### What to Expect

- **Acknowledgement**: You will receive an acknowledgment of your report within **48 hours**.
- **Updates**: I will keep you updated on the progress every 3-5 business days.
- **Resolution**: Once the issue is validated and fixed, you will be credited (if you wish) and notified.
- **Declined Reports**: If the vulnerability is declined, I will explain the reasoning behind the decision.

### Responsible Disclosure

Please allow reasonable time for the issue to be addressed before disclosing it publicly.

## Security Best Practices

When using or contributing to this project:

- **Use strong passwords** for any locally hosted applications
- **Keep dependencies updated** to the latest secure versions
- **Review code** before running it on production systems
- **Report suspicious activity** immediately
